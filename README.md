# ☕ Estudos em Java

Repositório destinado ao aprendizado contínuo da linguagem Java, com foco nos fundamentos, orientação a objetos, programação funcional, acesso a banco de dados, concorrência e recursos modernos da linguagem.

Os códigos representam prática ativa dos conceitos estudados ao longo da **Maratona Java Virado no Jiraya**, incluindo exercícios, exemplos e adaptações realizadas durante o processo de aprendizado.
